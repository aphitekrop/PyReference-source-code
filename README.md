**PyReference** — это open-source приложение, объединяющее более 1000 структурированных карточек, практические гайды и умный поиск. Всё работает без подключения к сети, а избранное синхронизируется через аккаунт.

## Ключевые особенности

- **100% Офлайн:** Вся база знаний (1000+ карточек) вшита в приложение. Работает в самолете, подвале и на даче.
- **Мгновенный поиск:** Ищет по названиям, параметрам, описаниям и тегам.
- **Мультиязычность:** Интерфейс и контент доступны на русском и английском языках.
- **Блок «Чем заменить»:** Уникальная фича! Узнайте, какие устаревшие методы Python стоит заменить на современные аналоги.
- **Полезные статьи:** Пошаговые руководства: от виртуального окружения до создания Telegram-бота и работы с БД.
- **Синхронизация:** Сохраняйте избранное в личном аккаунте (доступно и на телефоне, и в веб-версии).

## Для разработчиков

Проект состоит из генератора данных на Python и веб-интерфейса, упакованного в Android-приложение через Capacitor.

### Структура проекта
```text
├── index.html, entry.html      # Основной интерфейс справочника
├── articles.html, article.html # Раздел «Полезные статьи»
├── server.py                   # Локальный сервер + API для авторизации и избранного
├── scripts/                    # Скрипты генерации базы данных и утилиты
├── data/                       # Сгенерированная база (entries.json, articles.json)
└── assets/                     # Стили (CSS), скрипты (JS), иконки
```
